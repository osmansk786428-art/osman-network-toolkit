A Python networking toolkit for learning and basic network diagnostics in Termux.

## Features

1. Public IP Lookup
2. Network Calculator
3. View Saved Report
4. IP Range Generator
5. IP & Subnet Validator
6. Private/Public IP Detector
7. DNS Lookup
8. My Network Information
9. TCP Connectivity Test
10. Wi-Fi Information (Termux:API)
11. HTTP Header Checker
12. Export Network Report
13. Exit
14. Password Strength Checker
15. IPv4/IPv6 Validator
16. Advanced Subnet Practice
17. Offline Networking Practice
18. Generate Sample Password

## Requirements

- Android with Termux
- Python 3
- Internet connection for online features
- Termux:API for supported Wi-Fi information features

## Installation

Install Python if needed:

    pkg update
    pkg install python

Go to the project folder:

    cd ~/osman-cyber-lab/python

Run the toolkit:

    python Network-Toolkit.py

## Reports

- network_report.txt: saved report history
- network_report_export_*.txt: exported reports

Review reports before sharing them.

## Responsible Use

- Test only networks and systems you own or have permission to assess.
- Online lookups require internet access.
- Password-strength results are estimates.
- Never enter real passwords into demonstrations.
- This educational toolkit is not a professional security audit.
